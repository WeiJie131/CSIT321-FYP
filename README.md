
# GardenLens 🌱

GardenLens is a lightweight image recognition mobile web application developed for visitors of the Singapore Botanic Gardens.

The application aims to improve visitors' experiences by allowing them to identify plants, flowers and architectural features using image recognition technology.

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript
- ReactJS
- Vite

### Backend
- Node.js
- Express.js

### Database
- Supabase (PostgreSQL)
- Supabase JavaScript Client

---

Before running the project, install the following software:

## 🗄️ Step 4: Set Up Supabase

GardenLens uses Supabase as its cloud database.

Each team member does not need to install MySQL Server or MySQL Workbench.

### 4.1 Access the Supabase Project

1. Visit https://supabase.com/
2. Log in to your Supabase account.
3. Open the shared GardenLens project.

### 4.2 Create the Users Table

If the users table has not been created yet:

1. Open the Supabase project.
2. Navigate to **SQL Editor**.
3. Click **New Query**.
4. Execute the following SQL:

```sql
CREATE TABLE public.users (
    user_id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    username VARCHAR(100) NOT NULL,
    email VARCHAR(150) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

The database should now contain:

- Database: `postgres`
- Schema: `public`
- Table: `users`

Note: Run this SQL only once. If the table already exists, do not recreate it.

## 🔐 Step 5: Configure Environment Variables

Each team member must create their own `.env` file inside the `backend` folder.

The file location should be:

```text
backend/.env
```

Add the following configuration:

```env
SUPABASE_URL=YOUR_SUPABASE_PROJECT_URL
SUPABASE_SECRET_KEY=YOUR_SUPABASE_SECRET_KEY
PORT=5000
```

### Where to find your Supabase credentials

1. Open your Supabase project.
2. Navigate to **Project Settings → API Keys**.
3. Copy the Project URL.
4. Copy the Secret key.
5. Paste both values into your `.env` file.

**Important:**

- Replace the placeholders with your actual Supabase credentials.
- Do not upload your `.env` file to GitHub.
- Never expose your Supabase Secret key in frontend code.
- Each team member should configure their own `.env` file.

## 🚀 Step 6: Run the Backend Server

Open a VS Code terminal.

Navigate into the backend folder:

```bash
cd backend
```

Start the backend development server:

```bash
npm run dev
```

If everything is configured correctly, the terminal should display:

```text
GardenLens server running on port 5000
```

To test the backend API, open the following URL in your browser:

http://localhost:5000/

Expected response:

```json
{
  "message": "Welcome to GardenLens API!",
  "database": "Supabase connected successfully"
}
```

Keep the backend terminal running.

http://localhost:5173/

## ⚠️ Important Notes

- Both frontend and backend servers must be running to use the complete application.
- The frontend normally runs on port `5173`.
- The backend normally runs on port `5000`.
- Supabase is hosted online, so no local database server is required.
- Each team member must create their own `backend/.env` file.
- Team members must use the shared GardenLens Supabase project credentials.
- Never commit `.env` files or secret keys to GitHub.
- Do not create duplicate database tables if the shared table already exists.
